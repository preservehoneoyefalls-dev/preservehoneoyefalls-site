# Preserve Honeoye Falls website

Live at https://preservehoneoyefalls.org (hosted on Netlify, which publishes every change to this repository automatically).

## How to edit

**Easiest:** go to https://preservehoneoyefalls.org/admin, click **Login with GitHub**, change the words, and click **Publish**. The site updates in about a minute.

You need a free GitHub account that has been added to this repository as a collaborator.

## Where things are

- `content/home.json` – all the words on the homepage
- `content/pages/` – extra pages (each shows at /p/page-name)
- `uploads/` – pictures and files added in the editor
- `index.html`, `page.html`, `assets/` – the design. Normal edits never need to touch these.
- `admin/` – the editor
